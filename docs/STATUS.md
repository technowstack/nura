# STATUS: Proyek Nura

Terakhir diperbarui: 2026-11-15

Cabang utama: `main`. Setiap fase dikerjakan di branch sendiri (`feat/phase-N-<nama>`), lalu `merge --no-ff` ke `main` setelah review akhir. Fase 1 dikerjakan di `rebuild/nura` dan sudah di-merge lokal ke `main` (merge commit `7b0340c`). `main` sudah di-push ke `origin` (2026-11-15).

## Ringkasan Kondisi

- Arah proyek: rebuild bersih menjadi aplikasi Islami offline-first. Kode lama tidak ditambal.
- Repo lama (`main`, sebelum rebuild, HEAD `933deb5`): aplikasi Quran berbasis API, sekitar 25–30% jadi. Dijadikan referensi tampilan saja.
- Data JSON Quran dan hadis sudah dipindah ke `data-source/` dan di-track git. `CHECKSUMS.sha256` dan `README.md` sudah dibuat.
- Working tree lama yang kotor sudah dirapikan menjadi commit terpisah di `main` (platform, kode UI lama, docs, data).
- Tahap saat ini: Fase 1 (Fondasi) selesai. PRD v0.4, spec desain v1 (`docs/specs/2026-11-09-nura-v1-design.md`, disetujui), dan desain UI putaran 1 (`docs/design/`) sudah ada. Fase 2 (Al-Qur'an offline) selesai: lolos review akhir dan uji perangkat (oleh pemilik proyek, perangkat fisik), dan di-merge ke `main`. Fase 3 (Hadis) selesai: lolos review akhir dan uji perangkat (oleh pemilik proyek: aplikasi jalan dan hadis tampil), dan di-merge ke `main`. Fase 4 (Pencarian) selesai: uji fungsional di perangkat lulus (pemilik proyek, 2026-11-15), pengukuran kinerja menyusul; di-merge ke `main`. Fase 5 (Jadwal sholat) selesai di kode di `feat/phase-5-prayer`; uji perangkat sebagian lulus (pemilik proyek, 2026-11-15): pemilihan wilayah dan jadwal sholat berjalan, notifikasi tepat waktu (Isya) lulus, notifikasi setelah restart perangkat lulus; sisa daftar uji belum dilaporkan.
