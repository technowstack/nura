## Ringkasan Kondisi

- Arah proyek: rebuild bersih menjadi aplikasi Islami offline-first. Kode lama tidak ditambal.
- Repo lama (`main`, sebelum rebuild, HEAD `933deb5`): aplikasi Quran berbasis API, sekitar 25–30% jadi. Dijadikan referensi tampilan saja.
- Data JSON Quran dan hadis sudah dipindah ke `data-source/` dan di-track git. `CHECKSUMS.sha256` dan `README.md` sudah dibuat.
- Working tree lama yang kotor sudah dirapikan menjadi commit terpisah di `main` (platform, kode UI lama, docs, data).
- Tahap saat ini: Fase 1 (Fondasi) selesai. PRD v0.4, spec desain v1 (`docs/specs/2026-11-09-nura-v1-design.md`, disetujui), dan desain UI putaran 1 (`docs/design/`) sudah ada. Fase 2 (Al-Qur'an offline) selesai: lolos review akhir dan uji perangkat (oleh pemilik proyek, perangkat fisik), dan di-merge ke `main`. Fase 3 (Hadis) selesai: lolos review akhir dan uji perangkat (oleh pemilik proyek: aplikasi jalan dan hadis tampil), dan di-merge ke `main`. Fase 4 (Pencarian) selesai: uji fungsional di perangkat lulus (pemilik proyek, 2026-11-15), pengukuran kinerja menyusul; di-merge ke `main`. Fase 5 (Jadwal sholat) selesai dan di-merge ke `main`; uji perangkat lulus (pemilik proyek, 2026-11-15): pemilihan wilayah dan jadwal sholat berjalan, notifikasi tepat waktu (Isya) lulus, notifikasi setelah restart perangkat lulus; sisa daftar uji belum dilaporkan. Fase 6 (1 Hari 1 Ayat/Hadis: kartu Beranda, widget Android, notifikasi harian) selesai dan di-merge ke `main` (2026-11-16); uji perangkat pemilik: kartu, widget hadis, dan widget ayat tampil rapi (widget ayat memakai daftar ayat sementara, Q9 terbuka); pemeriksaan sampel matan kedua masih syarat rilis.
